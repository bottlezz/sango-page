# 公共区域与牌堆功能记录

记录日期：2026-09-08。状态：需求记录 + 交互建议，尚未接入正式游戏。

## 已明确的规则

1. 弃牌部分需要能查看所有打出和弃置的牌，不能只保留最后几张。
2. 牌堆支持从顶部摸牌，牌进入手牌。
3. 判定的基本流程：展示牌堆第一张牌，再将其放入弃牌堆。
4. “展示”和“放入弃牌堆”是两个独立动作。展示的牌也可以收入手牌，不能展示后立即强制弃置。
5. 特殊技能支持观看牌堆顶部 X 张牌，重新排列顺序，并允许将其中的牌放到牌堆底。
6. 用户倾向：弃牌堆平时收起，点击时才显示全部，让桌面更整洁。

## 建议的区域划分

| 区域 | 常态 | 展开／操作 |
| --- | --- | --- |
| 牌堆 | 一叠牌背、剩余数量、摸牌主按钮 | 设置张数；展示；判定；观看并整理牌顶 |
| 展示与结算区 | 仅显示正在处理的公开牌；空闲时留白 | 每张牌可“收入手牌”或“放入弃牌堆” |
| 弃牌堆 | 数量和“查看全部”入口 | 弹层显示完整牌面、来源和先后顺序 |

不建议继续把公共区域和弃牌混成一张密集的大网格。弃牌浏览建议用覆盖在桌面上的弹层，不推动玩家卡和手牌位置；关闭后回到原桌面。

## 交互建议

- **摸牌**：默认 2 张，允许输入正整数；从牌顶依序移入本人的手牌。摸牌不公开牌面。
- **展示**：取出指定数量的顶牌到公开展示区；留在这里等待玩家选择去向。
- **判定**：快捷展示 1 张并标记“判定”；玩家处理判定结果后，再点击放入弃牌堆。原型不自动推断技能效果或判定成功与否，也保留收入手牌的分支。
- **观看并整理**：独立弹层，明确“仅你可见”。分为“放回牌顶”和“放入牌底”两列，提供前移／后移、移到另一列按钮；未来可增加拖拽作为快捷方式。
- **顺序语义**：牌顶列从上到下是接下来依次摸到的牌；牌底列从上到下依次追加在剩余牌堆后，最后一张是最终牌底。提交前两列每张牌必须恰好出现一次。
- **确认与取消**：整理时只修改草稿，确认后整体应用。关闭、Esc、取消均丢弃草稿，原牌序不变。
- **并发与隐私**：正式实现应由服务端锁定整理中的牌堆，其他玩家只见“正在整理”；只向技能操作者发送可看的牌面，不能先发给所有客户端再用 CSS 遮挡。公开日志只写整理张数，不写私有牌面或顺序。
- **边界**：空牌堆、数量无效或超出剩余张数时阻止操作并提示。补牌／洗牌需后续明确规则，不在原型中自动执行。

## 弃牌与历史的区别（待确认）

“所有打出和弃置的牌”建议同时满足两种查看需求：默认展示当前仍在弃牌堆的全部牌；另设“打出／弃置记录”保留完整历史。牌被技能取走或洗回牌堆后，不应仍算在当前弃牌堆数量中，但历史事件可以保留。

待确认：是否需要跨洗牌保留历史；技能允许哪些玩家观看；展示是否需要公开／私密两种模式；判定改判和其他技能插入的具体流程。以上未确定项均不视为已确认游戏规则。

- `SANGO_PUBLIC_TABLE_V3.html`：单独体验公共区域。
- 可体验摸牌、展示、判定展示、两种展示牌去向、完整弃牌浏览、牌顶观看／排序／放底／取消。
- 使用本地演示数据，刷新重置；“仅你可见”展示的是界面意图，尚无多人权限或服务端同步。完整桌面的原有手牌、行动日志仍是静态示例，本原型新增的摸牌反馈和新收手牌在公共区“本次收入”中查看。

## 后续实现验收

1. 连续摸牌应取出原牌顶顺序；其他玩家看不到牌面。
2. 展示后牌既不在牌堆也不在弃牌堆；选定去向后只存在于目标区域。
3. 弃牌浏览数量与实际集合一致，所有牌都能滚动查看，关闭不改变桌面布局。
4. 整理确认后顺序为：牌顶列 + 未观看的剩余牌 + 牌底列；取消后恢复原状。
5. 整理支持全部放顶、全部放底和两边混合；不丢牌、不复制牌。
6. 正式多人版本验证权限、并发锁与断线恢复，并区分当前弃牌和历史事件。
