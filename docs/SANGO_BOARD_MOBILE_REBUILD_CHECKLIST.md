# SANGO 移动端牌桌重建清单

本轮以 `SANGO_BOARD_MOBILE_PLAN_E_COMPACT.html` 为视觉基准，使用独立移动端视图，复用现有 `gameController`、Firebase 订阅、`sg-card` 与 `sg-area`。旧的“直接压缩 desktop DOM”方案已经撤销。

## A. 结构与生命周期

- [x] 撤销上一版 mobile media-query 压缩方案。
- [x] 建立独立 `.mobile-board` 外壳；desktop 继续使用原布局。
- [x] 断点切换时只移动现有组件实例，不同时挂载两套 Firebase 订阅。
- [x] 玩家组件提供独立 mobile view；desktop `.widget` 不再承担手机排版。
- [x] 返回 desktop 时恢复牌区、武将和操作栏的原始挂载位置。

## B. 390px 主画面

- [x] 顶部栏压缩为品牌、房间号和公共工具入口。
- [x] 第一排固定显示四名对手，左右边界与公共桌面对齐。
- [x] 公共桌面占左侧三列，第五名对手占右侧一列。
- [x] 公共桌面高度限制为 `190–230px`，不会随高屏无限拉伸产生大块空白。
- [x] 行动日志作为公共桌面下方单行摘要。
- [x] 本地玩家摘要、区域标签、牌区、bottom bar 依次排列且不重叠。
- [x] 页面无横向滚动；牌区自身允许横向滚动。

## C. 玩家视图

- [x] 对手摘要显示玩家名、允许公开的身份、双将、体力、装备、区域数量和状态。
- [x] 整张对手卡打开区域面板。
- [x] 对手面板可切换手牌、区1、区2、装备、判定。
- [x] 本地摘要显示双将、身份、体力、状态和装备。
- [x] 本地使用手牌、区1、区2、装备、判定五个标签，一次只挂载一个真实牌区。
- [x] 切换本地区域时清除旧区域 selection。
- [x] 本地血量、翻面、连环、选将和上限操作复用现有行为，并由 bottom bar 的“玩家操作”打开。
- [x] Mobile 身份标记只继承身份色，不继承 desktop 的绝对定位与圆形尺寸。
- [x] 玩家操作面板显示在 bottom bar 上方，“血量上限”入口不会被遮挡。
- [x] 本地装备区移除空槽位和区域边框，以无边框横向装备列表呈现。
- [x] Mobile 武将卡与详情隐藏性别；亮将后隐藏亮将入口。
- [x] 玩家第一次亮出的武将自动成为主将；首次亮副将时原子交换主、副将区域。

## D. 公共桌面与 bottom bar

- [x] 公共桌面显示牌堆数量、最近八张弃牌以及最新到较早顺序。
- [x] Desktop 的最近八张弃牌以单行呈现；Mobile 以四列两行呈现，并使用紧凑牌面。
- [x] 未选牌时 bottom bar 提供摸牌、展示／判定、展开牌堆、查看弃牌和玩家操作；空牌堆显示洗牌。
- [x] 摸牌菜单支持 1–4 张。
- [x] 选牌后同一 bottom bar 切换为现有 selection 操作。
- [x] 查看全部弃牌和牌堆整理继续复用现有 dialog，并在手机上呈现为 bottom sheet。
- [x] 本地判定标签横向显示真实判定牌；本地摘要显示翻、链和判定状态。

## E. 验证

- [x] 390×844 完整对局截图与 Plan E 对照，主体结构已对齐；细节继续迭代。
- [x] 360px 页面无横向溢出，四张顶部玩家卡完整显示。
- [ ] 11+ 手牌、四件长装备、双长武将名压力检查。
- [ ] 翻、链、乐、兵、电同时存在时仍可辨认。
- [x] 已验证运行中从 mobile 切到 desktop，再切回 mobile，主要布局和区域恢复正常。
