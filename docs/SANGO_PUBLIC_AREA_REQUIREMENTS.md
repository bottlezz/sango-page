# 公共区域、牌堆与统一弃牌区需求

状态：当前讨论基线，替代旧版“展示后再手动放入弃牌堆”的规则。主体界面与现有容器交互已接入正式桌面；来源标签仅在当前会话通过 last-action 推断。

## 区域与术语

| 名称 | 含义 | 可见性 |
| --- | --- | --- |
| 牌堆 | 有顺序的牌集合，从顶部摸牌；可展开调整顺序 | 默认牌背；观看权限需另行确定 |
| 弃牌区 | 统一呈现最近弃牌与全部弃牌；牌只保存一份 | 所有人可见 |
| 弃牌堆 | 弃牌区中的完整历史集合，包括打出、弃置、牌堆展示／判定的牌 | 所有人可查看全部 |
| 最近弃牌 | 弃牌区主视图中按弃牌顺序截取的最近 6 张牌 | 所有人可见 |
| 亮牌 | 公开玩家某区域里的牌，保留原区域和归属 | 所有人可见；独立显示方案待定 |

弃牌区不再维护“结算批次”。游戏采用手动结算，系统没有可靠的回合结束或结算结束事件，因此不提供清算操作。

## 已确认操作

| 操作 | 牌的流向 | 弃牌区结果 |
| --- | --- | --- |
| 摸牌 | 默认取牌堆顶部 1 张 → 操作玩家手牌 | 不改变 |
| 展开／调整牌堆、观看牌顶 | 可调整顺序、放到底部，或加入“确认后摸牌” | 不改变 |
| 玩家打出 | 原区域 → 弃牌堆 | 成为最近弃牌 |
| 玩家弃置 | 原区域 → 弃牌堆 | 成为最近弃牌 |
| 牌堆展示／判定 | 默认取牌堆顶部 1 张 → 弃牌堆 | 成为最近弃牌 |
| 玩家亮牌 | 原区域及归属不变，只改公开状态 | 不改变 |
| 收取弃牌 | 弃牌堆 → 收取玩家手牌 | 从完整弃牌和最近弃牌中移除 |

不再提供“放入弃牌堆”和“清算”按钮。弃牌区主区域固定显示最近 6 张，按照最新到较早从左向右排列；右侧摘要显示全部弃牌数量，“查看全部”打开历史网格。

## 最近弃牌的更新

最近弃牌完全由弃牌堆的顺序得出，不需要新的结算 container、批次 ID、行动玩家或清算状态。

1. 打出、弃置或展示／判定产生新弃牌时，将其追加到弃牌堆末尾。
2. 主区域始终显示弃牌堆末尾最多 6 张，最新的在左，较早的在右。
3. 第 7 张新牌进入后，当前显示中最早的一张自然移出主区域，但仍可通过“查看全部”找到。
4. 从弃牌堆收入手牌后，该牌立即从主区域和全部弃牌中移除，不保留虚化占位。
5. 摸牌、整理牌堆、观看、亮牌、换玩家或换回合不会改变最近弃牌。
6. 洗牌会把弃牌实体移回牌堆，最近弃牌随弃牌堆清空。

## 牌堆展开与排序

- 摸牌使用分段按钮：左侧“摸 1 张”直接取一张，右侧下拉提供“摸 2 张／摸 3 张／摸 4 张”，点击选项即一次取走相应数量，不改变左侧默认值。剩余牌不足的选项禁用。
- “展示／判定”按钮不显示张数，行为固定取牌顶 1 张。两种操作都不要求键盘输入。
- “展开牌堆”进入排序界面，默认显示牌背和顺序编号。
- 提供前移、后移、放牌底／放牌顶，以及“确认后摸牌”。指定摸取的牌进入第三列，并在确认时加入操作玩家手牌。
- 确认是一个整体操作：从牌堆移出第三列的牌、写入玩家手牌并提交剩余牌序。关闭和 Esc 丢弃全部草稿，不摸牌，也不改变牌序。
- 取消可以撤销牌序与摸牌草稿，但不能撤回玩家已经看见的牌面；操作日志应保留观看行为所允许公开的最少信息。
- 不输入观看张数。展开界面中的每张牌都有“观看”按钮，玩家用鼠标逐张翻看；未点击的牌保持牌背。观看与公开并弃置的“展示／判定”不同。
- 最终顺序：牌顶列从上到下 → 牌底列从上到下；最后一张是最终牌底。“确认后摸牌”列按从上到下进入玩家手牌，不再留在牌堆中。
- 牌堆相关设计不要求键盘输入；摸牌、展示、观看、排序、放底和确认均可只用鼠标完成。
- 预览允许全堆排序以讨论交互。正式版本能排序的范围、能观看的范围应按技能或房间约定限制。

## 玩家亮牌的建议（尚未定案）

建议在原卡牌上标注公开，玩家卡旁提供“已亮牌”入口；展开后用只读牌面镜像呈现，明确玩家与来源区域。镜像不持有实体牌，也不能误触发弃置。

需要吸引全桌注意时，可短暂显示“玩家 A 亮出两张牌”通知，点击进入上述面板。独立展示可避免玩家误以为这些牌也被弃置。

待定：公开持续到何时、移动后是否仍公开、谁能暗置。此次原型使用原区域公开状态，不制作新的亮牌面板。

## 尚需推敲的情况

1. **打出与弃置语义**：两者都进入同一个弃牌堆，但日志仍需区分动作类型和操作者。
2. **判定改判**：旧判定牌和替换牌何时进入弃牌堆，仍需技能流程决定；预览不判断判定结果。
3. **收牌权限**：谁能从弃牌堆收牌、两个玩家同时收取如何处理，需要正式规则约束；界面入口不等于技能权限。
4. **洗牌与耗尽**：空牌堆显示洗牌入口；正式实现需原子地把弃牌移回牌堆。
5. **唯一归属与历史**：最近弃牌只是同一弃牌集合的窗口，收取不能复制。跨洗牌历史如有需要，应由行动日志承担。
6. **并发与私密观看**：正式版本需原子更新卡牌归属并锁定排序快照；未授权客户端不能收到私密牌面。
7. **断线与撤销**：最近弃牌可在重连后直接由弃牌顺序恢复；已经公开或观看的牌面无法从玩家记忆撤销。
